How to read the evidence markers

Each value carries the kind of evidence behind it, using the markers of the project's research dossier (docs/PREDICTION-SCIENCE.md).

M Measured in a laboratory, a fleet or an incident report.
S Simulated or calculated in the cited source (for example a vendor white paper's model or CFD).
V Vendor claim, not independently verified.
A Our assumption: no source was found, so the range is deliberately wide.
calc Arithmetic done by the team, with the script in research/scripts/.

Sources of truth for this document

Every figure traces to a file in the repository: the dossier and the implementation log in docs/, docs/ENGINE_CONTRACT.md, the engine code in src/domain/engine/ and server/director/, research/SOURCES.md, research/derived/*.json, research/data/published-transients/cooling_outage_points.csv and reports/validation-2026-11-08-*.md. Where the dossier and the implementation disagree, this document describes what was built and lists the dossier's extras as future work. The charts are generated by docs/pdf-src/build.mjs, which reads those files and, for two charts, runs the shipped engine functions (simulateThermal, evidencePosterior) with the parameters used in the project's own tests. Where a quantity was not measured, the text says "not measured".
