# Engine contract (`src/domain/engine/`)

All engine modules are pure TypeScript over `src/domain/types.ts`. The UI imports **only** from
`src/domain/engine/index.ts`. Numbers are produced here, never by the LLM. Randomness is seeded
(mulberry32) so a replay always produces identical output.

Scenario time is in **minutes** (`t`), where `t = 0` is scenario start. Clock values (`p10/p50/p90`)
are **absolute scenario minutes** at which a node is lost, not durations.

| File | Export | Signature / behaviour |
| --- | --- | --- |
| `rng.ts` | `mulberry32(seed)` | `() => number` in [0,1) |
| `cascade.ts` | `runCascade(facility, faults, opts)` | `faults: {assetId, t}[]`; `opts: CascadeOptions = { horizonMin: number; runs?: number (400); seed?: number (7); extraEdges?: DependencyEdge[] }`. Uses only `confirmed` edges plus `extraEdges`. Each run samples every edge delay from its triangular `{min,mode,max}`. Loss time of a node = min over its groups of (max over group members of `lossTime(member) + delay`); an edge with no `redundancyGroup` is its own group; a faulted node is lost at its fault `t`. Propagate with a Dijkstra-like relaxation until stable. Returns `Record<ID, ImpactClock>` for every node lost within the horizon in at least one run (percentiles over runs where lost, `null` if lost in < 10/50/90 % of runs as appropriate; `probWithinHorizon`; modal `path` from the fault to the node; `weakestAssumption` = `basis` of the edge on the path with the widest `max-min`). |
| `thermal.ts` | `inletTempAt(baseC, rackKw, coolingLostAt, t)` | Lumped first-order model. Before `coolingLostAt` (or when `null`) returns `baseC`. After it: `base + ΔTmax·(1 − e^(−(t−lost)/τ))` with `ΔTmax = 1.6·rackKw` °C and `τ = 4 + 60/rackKw` min. Document as indicative, not CFD. |
| `water.ts` | `simulateWater(facility, leak, horizonMin, frameEveryMin = 1)` | Height-field diffusion on a 0.5 m grid covering all zone rects. Ground height per cell = zone `elevation` (m). Cells outside zones are walls. Racks/equipment footprints (except `drain`, `pipe`) are plinths +0.05 m. Each substep: every cell passes water to lower neighbours (surface = ground + depth), capped flow per step, mass-conserving; drain cells remove 30 % per min of local depth. Source cell nearest `leak.{x,z}` adds `ratePerMin` litres/min starting at `leak.startT` (1 L over 0.25 m² = 4 mm). Returns `WaterGrid` with frames every `frameEveryMin`. |
| | `depthAt(grid, x, z, t)` | mm, nearest frame ≤ t |
| | `waterArrival(grid, facility, thresholdMm = 1)` | `Record<assetId, number>` first frame `t` at which any cell under the asset footprint (or within 0.5 m) is ≥ threshold. Pipe/drain assets excluded. |
| `readings.ts` | `freshness(reading \| undefined, now)` | `'missing'` if undefined; `'stale'` if `now − reading.t > 2 × expectedIntervalMin`; else `'fresh'`. |
| | `severityFor(metric, value, thresholds)` | Severity from `Threshold` (`dir` aware): ≥ alarm → `critical`, ≥ warn → `warning`, else `normal`. `leak` ≥ 0.5 → `critical`. |
| | `readingKey(r)` / `latestReadings(readings, now, sources?)` | key `assetId|metric|source`; latest reading per key with `t ≤ now`. |
| `verification.ts` | `compareReadings(installed, references, ctx)` | `ctx = { now: number; thresholds: Threshold[] }` → `{ verdict: Verdict; rationale: string; qualityFlags: string[] }`. Rules: metric/asset mismatch or no reference or a stale reference → `inconclusive`; both abnormal (≥ warn) → `corroborated_abnormal`; installed abnormal and reference normal with a material gap (> 3 °C temp, > 30 % vibration) → `measurement_disagreement`; installed normal and reference normal → `not_corroborated_in_session`. Rationale never says "sensor broken" or "equipment safe". |
| `priority.ts` | `rankIncidents(incidents, ctx)` | `PriorityContext = { facility; clocks: Record<ID, ImpactClock>; now: number; tasks: Task[]; employees: Employee[] }`. Factors (0–1 scores) with operator-configured illustrative weights: service impact (criticality of services on racks within the incident's downstream clocks) 0.30, urgency (minutes to earliest p50 downstream loss, ≤ 10 → 1) 0.25, redundancy (does incident remove a redundant path: CRAH pair, UPS pair, PDU pair) 0.15, evidence quality (corroborated 1, unverified 0.6, inconclusive 0.5, disagreement 0.25, not_corroborated 0.3 — disagreement still keeps a floor, never zero) 0.15, resource feasibility (eligible available employee exists) 0.10, consequence of wrong action 0.05. Return sorted desc, each with `policyVersion = POLICY_VERSION`, `factors[].note` human-readable, and `resolvingCheck` when evidence is `unverified`/`inconclusive`/`measurement_disagreement`. |
| `routing.ts` | `findRoute(facility, fromWp, toWp, opts)` | `opts = { skills: Skill[]; closedEdgeIds?: ID[]; walkSpeedMps?: 1.2 }`. Dijkstra over `walkEdges` (undirected), skipping `closed` / `closedEdgeIds` / `restrictedTo` not in skills. Returns `Route` with `etaMin` (+0.5 min per restricted door), `assumptions` (walk speed, check-in source), or `ok:false` with `blockedReason`. Never straight-line fallback. |
| `tasks.ts` | `transition(task, action, ctx)` | `TaskAction = {type:'assign', ownerId} \| {type:'accept'} \| {type:'decline', reason} \| {type:'depart'} \| {type:'arrive'} \| {type:'confirm_asset', scannedId} \| {type:'start'} \| {type:'record_step', stepId, result, note?, evidenceId?} \| {type:'block', reason} \| {type:'unblock'} \| {type:'submit'} \| {type:'approve'} \| {type:'request_changes', reason} \| {type:'reopen', reason} \| {type:'cancel', reason}`. `ctx = { actor: string; t: number; expectedVersion: number }`. Version mismatch → error `stale_version`. Illegal transition → error. `confirm_asset` with wrong id → error `asset_mismatch` (A13). `start` requires `assetConfirmed`. `submit` requires all required steps recorded (`canComplete`). `submit` on a no-review task goes straight to `completed`. Returns `{ok:true, task (version+1), event: OpEvent}` or `{ok:false, error}`. Never mutate input. |
| | `suggestAssignees(task, employees, facility, now)` | `AssigneeSuggestion = { employeeId; eligible: boolean; reasons: string[]; route?: Route; score: number }`. Filter by skills, zone access (asset zone in `zones`), availability; rank by eta (route from last check-in; stale check-in > 30 min adds a "location stale" reason and +5 min penalty), workload. Sorted best first; ineligible included with reasons. |
| `handoff.ts` | `buildHandoff(input)` | `HandoffInput = { now; incidents; tasks; employees; events: OpEvent[]; verifications: VerificationSession[]; clocks; staleAssetIds: ID[]; facility }` → `HandoffNote = { generatedAt: number; source: 'local_rules'; happening: string[]; verified: string[]; uncertain: string[]; done: string[]; owners: {item, owner}[]; doNotRepeat: string[]; watch: {assetId, atMin, why}[] }`. `handoffToMarkdown(note, wallClock: (t)=>string)`. |
| `simulate.ts` | `simulateScenario(input)` | `ScenarioRunInput = { facility; scenario; seedReadings: Reading[]; extraEdges?: DependencyEdge[]; extraFaults?: {assetId,t}[] }` → `ScenarioRun = { clocks; water?: WaterGrid; waterArrival: Record<ID, number>; derivedEdges: DependencyEdge[]; readingsAt(t): Reading[]; visualAt(t): Record<ID, AssetVisualState>; stepsUntil(t): ScenarioStep[] }`. Wet assets (from `waterArrival`) become faults at arrival `t` and get a derived `shares_space` edge (`basisKind: 'model'`, basis "water-layer arrival, approximation"). `readingsAt(t)` = seed readings + scenario step readings + synthesized readings for racks whose cooling clock has passed (via `inletTempAt`), only `t ≤ now`. `visualAt(t)`: severity = max(threshold severity of latest installed reading, clock severity — lost by `t` → critical, `p50 − t ≤ 10` → critical, `≤ 30` → warning, else advisory if on any clock); freshness from installed readings; `heat` = clamp((inlet − 18)/14); `clockMin = p50 − t` if > 0; `wet` if arrival ≤ t. Memoize per `t`. |
